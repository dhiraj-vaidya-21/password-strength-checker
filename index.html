🧠 DSA Concepts Implemented
🔤
Strings
Password treated as a character array. Traversed character-by-character for analysis.
Time: O(n) | Space: O(k)
📦
Arrays
Common passwords list, weak patterns list, and rules stored as Arrays. Sorted array used for Binary Search.
Lookup: O(n) | Access: O(1)
🗄️
Hash Set
JavaScript Set used as hash table for O(1) average common-password lookup. Demonstrates hashing concept.
Lookup: O(1) avg | Space: O(m)
📚
Stack (LIFO)
Custom Stack class with push/pop/peek/isEmpty. Analyzes repeat-character runs and pattern depth.
All ops: O(1) | Space: O(n)
🔍
Linear Search
Manually implemented to detect weak sub-patterns and sequential keyboard patterns inside the password.
Time: O(n·m·p) | Space: O(1)
🔎
Binary Search
Applied on sorted common-password array. Halves search space each step — much faster than linear.
Time: O(log n) | Space: O(1)
🔄
Bubble Sort
Manually implemented to sort password rules by score in descending order. Shows each pass and swap count.
Time: O(n²) | Space: O(1)
🔃
Selection Sort
Used to sort improvement suggestions by priority level. Finds the next best suggestion at each step.
Time: O(n²) | Space: O(1)

📖 About This Project

Project Overview

This is a college-level DSA project demonstrating how fundamental data structures and algorithms can be applied to solve a real-world security problem: evaluating password strength. The entire analysis runs client-side in the browser.

Key Features

  • Real-time password strength analysis
  • 7+ DSA concepts visibly implemented
  • Live visualizations of each algorithm
  • Time & space complexity display
  • Improvement suggestions sorted by priority
  • Fully responsive, modern UI

Strength Levels

  • 🔴 Very Weak — Score 0–2 or common password
  • 🟠 Weak — Score 3–4
  • 🟡 Medium — Score 5–6
  • 🟢 Strong — Score 7–8
  • 🔵 Very Strong — Score 9–10

Technologies Used

  • HTML5 — Semantic structure
  • CSS3 — Glassmorphism, animations
  • Vanilla JavaScript — All logic & DSA
  • No frameworks, no backend, no APIs
  • Google Fonts (Inter, JetBrains Mono)
🛡️ Password never stored, logged, or transmitted · 100% Client-Side Processing
